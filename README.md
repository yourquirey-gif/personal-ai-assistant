# Personal AI Assistant

Web-first personal AI assistant MVP.

## MVP
- AI chat
- Web research (planned)
- Information search and comparison (planned)
- Study/research assistance
- Job research
- Personal task planning

## Architecture
- Frontend: React + TypeScript + Vite
- Backend: Node.js + TypeScript + Express
- AI: OpenRouter through the backend only
- Deployment target: Vercel (frontend) + Render (backend)

## Security
Never put API keys in frontend code or commit real secrets. Use environment variables.
